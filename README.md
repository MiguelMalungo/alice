# Alice in Brewland

One-page site for the Alice in Brewland brunch café, Rua do Almada 334, Porto. Concept: *the scroll is the fall*.

- Live: https://miguelmalungo.github.io/alice/
- Source: [`site/`](site/) (Vite + TypeScript, GSAP, Lenis, three.js). See [`site/README.md`](site/README.md) to run locally.
- Design plan: [`DESIGN-PLAN.md`](DESIGN-PLAN.md)
- Reference assets pulled from the Figma prototype: [`assets/figma-ref/`](assets/figma-ref/)

Deploys to GitHub Pages on every push to `main` via `.github/workflows/pages.yml`.
